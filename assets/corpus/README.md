# 训练 / 台词语料（不含音频）

本目录是「御姐·原声库」的文本语料，**只有文本，不含任何音频**。音频由本地 TTS 训练/生成流程产出，库包另行分发（`dsh-lib-yujie-v3.tar.bz2`，Opus 32kbps 单声道）。

| 文件 | 条数 | 用途 |
|---|---|---|
| `corpus538.txt` | 337 | 日常碎碎念（库 v3 的 `kind:"chatter"`，id `0001`–`0337`） |
| `corpus_meme27.txt` | 27 | 27 张表情包固定台词（`kind:"meme"`，id `M01`–`M27`，与表情包名一一对应） |
| `corpus_interact50.txt` | 50 | 点击桌宠互动台词（`kind:"interact"`，id `I01`–`I50`） |

约定：

- 一行一句，UTF-8，无空行；行号 = 音频编号（`0001.wav`… / `M01.wav`… / `I01.wav`…）。
- 库包 `index.json` 的 `text` 字段与这里逐行一致；播放时做「去空白 / 标点统一 / 全半角统一」后精确匹配。
- 这些文本也用于训练本地 VITS 音色（鱼鱼酱 / 鱼鱼姐），因此口径保持一致；改动文本会让库包与模型音色不同步。

许可与来源：用户本人提供/授权用于本地语音克隆与播放；仅供个人非商业使用，不含影视 / 游戏角色台词。
