② 一键安装（复制到 PowerShell 运行）

会自动下载（走国内加速）、装进 DSH、加进插件列表；装完重启 DSH。

$u = "https://gh-proxy.com/https://github.com/bbfang2025-cyber/dsh-pet-voice-fishy/releases/download/v1.3.2/dsh-pet-voice-fishy-1.3.2.tgz"
$tgz = "$env:TEMP\dsh-pet-voice-fishy.tgz"
Invoke-WebRequest -Uri $u -OutFile $tgz
$p = "$env:USERPROFILE\.dsh\profiles\desktop"
Set-Location $p
pnpm remove dsh-pet-voice 2>$null
pnpm add "file:$tgz" --registry=https://registry.npmmirror.com
node -e "const fs=require('fs');const f='package.json';const j=JSON.parse(fs.readFileSync(f,'utf8'));j.dsh=j.dsh||{};j.dsh.profile=j.dsh.profile||{};const b=(j.dsh.profile.bundles||[]).filter(x=>x!=='dsh-pet-voice');if(!b.includes('dsh-pet-voice-fishy'))b.push('dsh-pet-voice-fishy');j.dsh.profile.bundles=b;fs.writeFileSync(f,JSON.stringify(j,null,2))"
Write-Host "安装完成，请完全退出并重启 DSH"

③ 离线音色包也不用翻墙

插件里点「离线音色 → 下载」时，模型会走 gh-proxy / ghfast 等国内加速线路自动下载（约 348MB，支持断点续传），不需要 VPN。
